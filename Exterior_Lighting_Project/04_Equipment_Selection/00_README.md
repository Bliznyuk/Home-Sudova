# Вибір обладнання

Ця папка - місце, де порівнюються варіанти, фіксуються рекомендації і записується фінальний вибір.

Тут має бути видно:

- які варіанти розглядали;
- чому один краще за інший;
- що рекомендує Codex;
- що обрав власник;
- чи рішення фінальне;
- які посилання на покупку.

## Файли

| Файл | Призначення |
|---|---|
| `01_Neon_Comparison.md` | порівняння LED-неону / стрічок / профілів |
| `02_Downlight_Comparison.md` | порівняння світильників під навіс і терасу |
| `03_Power_Supply_and_Controller_Comparison.md` | блоки живлення, PWM, DALI, HA-реле |
| `04_Selection_Log.md` | фінальні рішення власника |

## Статуси вибору

- `кандидат`
- `рекомендовано`
- `відхилено`
- `обрано`
- `куплено`
