# Порівняння downlight

## Що потрібно

Для навісу і тераси потрібні теплі, не сліпучі світильники:

| Параметр | Вимога |
|---|---|
| Колір | 2700K |
| CRI | бажано 90+ |
| Захист | IP65 для навісу / зовнішньої підшивки |
| Потужність | 6-8W для декоративно-функціонального світла, 8-10W якщо потрібен яскравіший режим |
| Кут | 36-60 градусів |
| Димування | 24V PWM або DALI/0-10V/перевірений phase dimming |
| Колір корпусу | чорний / графіт / темна бронза |

## Тест перед закупівлею

Для 230V downlight обов'язково купити / позичити 1 зразок і перевірити:

- чи димується з обраним контролером;
- чи не мерехтить;
- чи не гуде драйвер;
- чи зберігає теплий тон на 20-30%;
- чи не сліпить під реальним кутом монтажу.
