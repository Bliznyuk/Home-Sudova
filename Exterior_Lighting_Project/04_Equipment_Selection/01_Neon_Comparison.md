# Порівняння неону

## Базова специфікація для нашого проєкту

Потрібна "робоча конячка", не преміум:

| Параметр | Вимога |
|---|---|
| Тип | гнучкий LED-неон або LED-профіль warm white |
| Колір | 2700K, не yellow |
| Напруга | 24V DC |
| Потужність | 8-10 W/м для фасаду/навісу; 4.8-6 W/м для сходів, якщо достатньо |
| Захист | IP65 під дахом, IP67 для сходів / вологи |
| Димування | 24V PWM |
| Монтаж | алюмінієвий канал / кліпси, доступні з'єднання |
