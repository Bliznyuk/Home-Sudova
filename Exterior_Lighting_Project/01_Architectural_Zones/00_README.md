# Архітектурні зони

Кожна архітектурна зона ведеться у своїй папці. У папці зони зберігаються:

- `00_Brief.md` - дизайнерське й електричне ТЗ по конкретній зоні;
- `` - вихідні фото цієї зони;
- `` - майбутні рендери / варіанти;
- `Decision_Log.md` - короткий журнал прийнятих рішень саме по цій зоні, якщо потрібно.

## Поточні зони

| Папка | Зона |
|---|---|
| `01_Main_Entry_Facade` | головний фасад, вхід, сходи, портал |
| `02_Carport` | простір під навісом / автонавіс |
| `03_Terrace` | тераса, дерев'яна стіна, сходи, задній садовий вихід |

## Принцип

Глобальні файли в корені проєкту описують загальну логіку, але фінальні рішення по конкретній зоні фіксуються у папці відповідної архітектурної зони.
