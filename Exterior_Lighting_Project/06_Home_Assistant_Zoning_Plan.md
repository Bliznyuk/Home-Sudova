# План зонування Home Assistant

Цей файл - нагадування для етапу, коли буде зібрана повна специфікація світильників, неону, фасаду, тераси, навісу, саду, брами і зовнішнього освітлення.

## Мета

Розкласти все освітлення не просто за електричними лініями, а за реальними user flow, сценаріями і мікросценаріями використання будинку.

## Що потрібно зробити

1. Зібрати повну відомість світильників:
   - фасад;
   - головний вхід;
   - сходи;
   - навіс;
   - тераса;
   - сад;
   - доріжки;
   - брама;
   - технічні / сервісні зони;
   - зовнішні розетки / резерв.

2. Розділити освітлення на логічні HA-зони:
   - `front_entry`;
   - `front_facade`;
   - `entry_steps`;
   - `canopy`;
   - `terrace`;
   - `terrace_side_facade`;
   - `garden_front`;
   - `garden_back`;
   - `gate_driveway`;
   - `service_light`;
   - `night_orientation`.

3. Описати user flow:
   - приїзд додому на авто;
   - підхід від брами до входу;
   - вихід на терасу ввечері;
   - діти / сімейний режим у дворі;
   - нічна орієнтація без яскравого світла;
   - технічне обслуговування / прибирання;
   - режим "нікого немає вдома";
   - святковий / гостьовий режим.

4. Описати сцени:
   - `Evening`;
   - `Arrival`;
   - `Parking`;
   - `Terrace Dinner`;
   - `Kids Outside`;
   - `Night`;
   - `Service`;
   - `Away`;
   - `All Off`.

5. Описати мікросценарії:
   - датчик руху біля брами вмикає не весь двір, а тільки орієнтаційне світло;
   - відкриття хвіртки піднімає світло доріжки і входу;
   - заїзд авто піднімає світло навісу на 5-10 хвилин;
   - тераса ввечері не вмикає фасад на 100%, а працює м'якою групою;
   - боковий фасад біля тераси працює окремо на 15-30%, щоб не перетворювати терасу на LED-рамку;
   - після певного часу декоративне світло знижується до нічного рівня;
   - технічний режим тимчасово дає 100% тільки потрібній зоні.

6. Для кожної HA-групи визначити:
   - які світильники входять;
   - 24V чи 230V;
   - тип димування: PWM, DALI, 0-10V, phase dimming або on/off;
   - блок живлення / драйвер;
   - місце сервісної шафи;
   - ручний fallback;
   - default brightness для основних сцен.

## Принцип

Електричні групи мають підтримувати сценарії життя, а не тільки зручність монтажу. Краще більше логічних груп із низькою яскравістю, ніж одна велика група, яка вмикає весь двір одразу.
