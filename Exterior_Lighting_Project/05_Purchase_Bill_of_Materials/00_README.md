# Номенклатура закупівлі

Ця папка має стати фінальною закупівельною відомістю: що саме купуємо, скільки, де, за якою ціною і для якої зони.

## Файли

| Файл | Призначення |
|---|---|
| `01_Bill_of_Materials.md` | основна таблиця закупівлі |
| `02_Store_Links.md` | чистий список посилань |
| `03_Purchase_Status.md` | що куплено, що очікує, що замінено |

## Правило

Позиція потрапляє в номенклатуру тільки після того, як вона:

1. порівняна в `04_Equipment_Selection`;
2. рекомендована або обрана;
3. має кількість;
4. має зону застосування;
5. має посилання або точну назву для закупівлі.
