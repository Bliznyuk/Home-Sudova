# Ландшафтне освітлення

Це місце для окремого проєктування світла саду, доріжок, декоративних трав, дерев, брами і заднього двору.

## Робочі папки

- `` - вихідні фото переднього двору, брами, заднього двору і технічних проходів.
- `` - майбутні рендери / варіанти ландшафтного освітлення.

## Зони ландшафту

| ID | Зона | Що потрібно освітити | Статус |
|---|---|---|---|
| LND-01 | передній фасад / вхід | трави, гравій, доріжка, підхід до сходів | чернетка |
| LND-02 | навіс зовнішній край | гравійна смуга, декоративні трави вздовж колон | чернетка |
| LND-03 | тераса / задній сад | рослини перед терасою, перехід у сад | чернетка |
| LND-04 | брама / під'їзд | в'їзд, хвіртка, маршрут до входу | треба деталізувати |
| LND-05 | задній двір | дерева, зона дітей, піщаник / майбутній газон | треба деталізувати |
| LND-06 | технічні зони | свердловина, стічні ями, сервісні проходи | треба деталізувати |

## Принципи

- Максимум 2700K.
- Бажано 24V для садового світла.
- Світильники ховати в посадках, не робити "аеропортну" доріжку.
- Садове світло має бути нижчим за фасадне, щоб не конкурувати з архітектурою.
- Для дерев і трав краще малі spike-світильники 1-3W або 3-5W, залежно від висоти рослин.
- Кабелі вести в трубах, з можливістю змінити розташування після посадок.
