# Кошторис і розрахунок вартості

Ця папка призначена для розрахунку вартості по етапах, зонах і закупівельних позиціях.

## Файли

| Файл | Призначення |
|---|---|
| `01_Estimate_Template.md` | таблиця для ручного розрахунку |
| `02_Purchase_Phases.md` | що купувати зараз, що можна відкласти |
| `03_Budget_Summary.md` | зведений бюджет після заповнення |

## Принцип

Спочатку фіксуємо рішення й номенклатуру, потім рахуємо:

1. світильники;
2. неон / LED-профілі;
3. блоки живлення;
4. контролери / димери / HA-реле;
5. кабель і труби;
6. монтажні матеріали;
7. робота електрика;
8. запас / резерв 10-15%.
