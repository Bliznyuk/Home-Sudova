# Відомість ліній, світильників і живлення

## Координати для навісу

Навіс: 3.54 м ширина x 11.85 м довжина.

```text
X = 0.00 м    стіна будинку
X = 0.85 м    ряд A downlight біля стіни
X = 2.15 м    ряд B downlight ближче до авто / колон
X = 2.75-2.85 м лінія неону по внутрішній стороні зовнішньої балки
X = 2.94 м    лінія зовнішніх колон
X = 3.54 м    зовнішній край даху / навісу

Y = 0.00 м    передній край навісу, ближче до головного фасаду
Y = 11.85 м   дальній край навісу, ближче до тераси / задньої частини
```

## Неон: потрібна специфікація

Потрібен не преміум-сегмент, а нормальна робоча конячка:

| Параметр | Вимога |
|---|---|
| Тип | гнучкий LED-неон warm white |
| Колір | 2700K, не yellow |
| Напруга | 24V DC |
| Потужність | 8-10 W/м |
| Світловий потік | орієнтовно 300-500 lm/м |
| Розмір | 6 x 12 мм достатньо |
| Захист | IP65 під навісом/софітом, IP67 для зон біля сходів/вологи |
| Оболонка | силікон |
| Різка | бажано кожні 25-50 мм |
| Димування | 24V PWM dimmer/controller |
| Монтаж | алюмінієвий канал або кліпси, не просто клей |

Не брати: 220V неон, RGB, жовтий неон, 12V для довгих ліній, 14-20 W/м без потреби.

## Лінії неону

| ID | Де | Довжина | Сегменти | Потужність | БЖ |
|---|---|---:|---|---:|---|
| L1 | Головний фасад під звисом, тільки над стіною будинку | 12.72 м | 3 x ~4.24 м | 12.72 x 8.8W = ~112W | 24V 150W |
| L2 | Навіс, уздовж зовнішньої балки / лінії колон | 12.645 м за Figma, координаційно ~12.65 м | 3 x ~4.215 м, округлено 3 x ~4.22 м | 12.645 x 8.8W = ~111W | 24V 150W |
| L3 | Сходи головного входу, LED-сегмент за Figma | ~8.44 м | 2 x ~4.22 м | якщо 6W/м: ~51W | 24V 75W |
| L4 | Права бокова стіна під звисом, опційно | 11.85 м | 3 x ~3.95 м | ~104W | 24V 150W |

Базовий комплект зараз: L1 + L2 + L3. L4 - опція.

Важливо: L1 на головному фасаді закінчується на рівні стіни будинку. Вона не продовжується по всьому даху навісу.

L2 / навіс: сегментація `3 x ~4.215 м` є координаційним правилом для планування. Перед закупівлею і різом електрик має підтвердити фактичну довжину на об'єкті, інтервал різки конкретного неону, падіння напруги, точки живлення і доступ до з'єднань.

Детальне ТЗ головного входу: `01_Architectural_Zones/01_Main_Entry_Facade/00_Brief.md`.

## Рекомендована сервісна шафа під навісом

У дальньому торці навісу, за дерев'яним рейковим екраном, передбачити IP65 сервісну шафу:

- 24V БЖ для L2;
- контролер PWM для L2;
- БЖ/контролер для колон;
- резерв 24V;
- клеми, запобіжники, підписані лінії;
- доступ для обслуговування без демонтажу фасаду.

БЖ фасаду L1 і сходів L3 можна винести в окрему шафу біля входу/технічної зони, щоб не тягнути довгі 24V траси.

## Порада по закупівлі неону

Шукати позицію типу:

```text
Гнучкий LED-неон 24V, 2700K warm white, 6x12 мм, IP65/IP67, 8-10 W/м, 120 LED/м або аналог, силікон, PWM dimmable, різка 25-50 мм.
```

Artled 24V 2700K 8.8W/м - правильний тип.  
Gamma за раніше наданим посиланням - yellow, не підходить для архітектурної warm white підсвітки фасаду.

| ID | Де | Довжина / кількість | Потужність | БЖ |
|---|---|---:|---:|---|
| T1 | downlight у підшивці даху тераси | 4 шт. | 4 x 8W = 32W | якщо 24V: 60W або 75W |
| T2 | одна сходинка тераси на всю ширину | 1 x ~6.30 м | якщо 6W/м: ~38W | 24V 60W |
| T3 | підсвітка дерев'яної стіни | 2-3 світильники або коротка прихована лінія | 20-40W | 24V 60W |
| T4 | садовий край біля тераси | 4-6 малих світильників | 20-40W | 24V 60W |
| T6 | боковий фасад біля тераси, під звисом | ~6.52 м за Figma | якщо 8.8W/м: ~57W | 24V 100W |

Для сходинки тераси використовувати IP67 профіль/неон або LED-профіль, придатний для зовнішнього монтажу і прибирання. Усі з'єднання мають бути доступні для ревізії.

T6 - це окрема фасадна лінія стіни біля тераси, не продовження LED-контуру тераси. Димувати окремо від `light.terrace_downlights` і `light.terrace_steps`.
