# Exterior_Lighting_Project House Sudova

Цей комплект документів фіксує поточну концепцію зовнішнього освітлення, матеріалів і керування світлом для будинку.

Стиль: organic modern / сучасний природний мінімалізм. Головна ідея: тепле, м'яке, шарове світло, натуральне дерево, камінь, гравій, декоративні трави. Без cold white, RGB, хай-тек контуру по всьому даху або ефекту готельного фасаду.

## Актуальний реєстр джерел

Перед використанням розмірів, Figma-шарів, планів, reference-зображень або старих prompt/кошторисних нотаток перевірити `../planning/source-register.md`. Там зафіксовано, що є Known / Observed / User-provided / Assumption / Missing, а також конфлікти між Figma, планами і попередніми документами.

## Головні рішення, які зафіксовані

1. Максимальна температура світла: 2700K. Краще 2400-2700K для декоративних ліній.
2. Головний фасад і навіс - дві окремі світлові сцени, не одна суцільна LED-рамка.
3. Лінія неону на головному фасаді закінчується на рівні стіни будинку і не продовжується по всій довжині даху навісу.
4. Під навісом неон іде однією лінією вздовж зовнішньої балки / лінії колон; N2/L2: 12.645 м за Figma, координаційно 3 x ~4.215 м / ~4.22 м, фінальний різ після заміру і перевірки виробу.
5. Балки підсвічуються непрямо: лінією неону, downlight між балками і м'якими тінями. Не обводити кожну балку стрічкою.
6. Усі декоративні 24V лінії мають бути димовані через Home Assistant-сумісні PWM-контролери.
7. Блоки живлення і контролери ставити тільки в доступні сервісні шафи / коробки, не замуровувати в фасад.
8. Тераса стає теплою дерев'яною нішею: зелена стіна зашивається деревом, дах підшивається, перед терасою одна широка сходинка на всю ширину з 2700K-підсвіткою.
9. Головний фасад фіксується як тепла вхідна сцена: дерев'яний портал, широкі сходи, фасадна лінія тільки над стіною будинку, без продовження по даху навісу.
10. Боковий фасад біля тераси - окрема спокійна світлова площина: м'яка лінія під звисом або делікатні washer/spike, не LED-рамка тераси.

## House-only уточнення 2026-07-01

Для поточного архітектурного етапу без освітлення використовувати `01_Architectural_Zones/00_House_Exterior_Brief.md`.

Додатково зафіксовано:

- сходи/подіуми з обох боків будинку мають бути явно на Figma плані;
- терасна стіна з двома дверима зашивається деревом;
- коротша / торцева стіна тераси лишається в колір фасаду;
- lighting-розділи попередніх brief не використовувати для цього house-only опису.
