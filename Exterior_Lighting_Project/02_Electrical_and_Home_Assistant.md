# Електрика та Home Assistant

## Головний принцип

Home Assistant може димити зовнішнє світло, але тільки якщо це закладено на рівні драйверів, контролерів і груп. Не кожен LED-світильник димується автоматично.

Правильна логіка:

```text
230V живлення -> захист -> блок живлення / dimmable driver -> HA-сумісний контролер -> світильник
```

Для 24V LED-ліній:

```text
230V -> БЖ 24V constant voltage -> PWM dimmer/controller -> LED neon / LED strip
```

## Рекомендована архітектура керування

### 24V декоративні лінії

Для неону, стрічок, сходів, колон і садових ліній:

- 24V DC constant voltage;
- PWM dimming після блока живлення;
- контролери в доступній IP65 шафі;
- бажано окремий PWM-канал на кожну важливу групу.

Групи:

1. фасадна лінія під звисом;
2. навіс - лінія по зовнішній балці;
3. сходи / подіум;
4. колони навісу;
5. сад / декоративні трави;
6. резерв.

### Downlight під навісом

Є два нормальні варіанти:

**Варіант A, рекомендований для стабільного HA-димування:**  
24V dimmable downlight / LED-модулі + загальний 24V PWM-контролер групи.

Плюси: простіше димити, єдина логіка з неоном, усе керується низькою напругою.  
Мінуси: треба підібрати саме 24V світильники з нормальним корпусом IP65.

**Варіант B, якщо беруть 230V downlight:**  
Вимагати dimmable-світильники/драйвери і HA-сумісне керування через DALI, 0-10V або якісний phase dimmer.

Плюси: більше моделей на ринку.  
Мінуси: треба тестувати сумісність до закупівлі всіх 10 шт.; дешеві LED-драйвери можуть мерехтіти, шуміти або погано димитись.

Висновок: для навісу краще або 24V PWM, або DALI/0-10V. Просте "поставимо LED і потім задимимо" - ризик.

### Технічне світло

Технічне світло для прибирання/паркування може бути on/off через HA-реле або датчик руху. Його не обов'язково димити.

|---|---|---|---|---|
| `light.facade_roofline` | L1, неон головного фасаду | так | 24V PWM controller | 24V 150W |
| `light.entry_portal` | бра / світло дерев'яного порталу | так, якщо модель підтримує | DALI / 0-10V / dimmable 230V або 24V PWM | залежить від світильника |
| `light.entry_steps` | L3, підсвітка сходів | так | 24V PWM controller | 24V 75W |

| `light.canopy_neon` | L2, лінія по зовнішній балці навісу | так | 24V PWM controller | 24V 150W |
| `light.canopy_columns` | світло на колонах | так | 24V PWM controller | 24V 40W |
| `light.canopy_service` | технічне світло навісу | не обов'язково | HA relay / motion sensor | 230V або 24V 60W |

| `light.terrace_downlights` | тераса, основні downlight | так | 24V PWM або DALI/0-10V | 24V 60-75W або dimmable drivers |
| `light.terrace_steps` | тераса, одна сходинка на всю ширину | так | 24V PWM controller | 24V 60W |
| `light.terrace_wood_wall` | тераса, дерев'яна стіна | так | 24V PWM або DALI/0-10V | 24V 60W |
| `light.terrace_garden` | тераса, садовий край | так, бажано | 24V PWM controller | 24V 60W |

## Вимоги перед закупівлею світильників

Перед закупівлею партії електрик або інтегратор має підтвердити:

1. Яка напруга світильника: 24V чи 230V.
2. Який тип димування підтримується: PWM, DALI, 0-10V, phase dimming або не підтримується.
3. Чи сумісний контролер із Home Assistant.
4. Який мінімальний стабільний рівень димування без мерехтіння.
5. Чи зберігається однакова температура 2700K на низькій яскравості.
6. Чи є доступ до драйвера/БЖ після монтажу.

Для 230V downlight обов'язково протестувати 1 зразок зі своїм димером/контролером до закупівлі всіх 10 шт.

## Де ставити блоки живлення і контролери

БЖ і контролери ставити тільки в доступному місці:

- технічна шафа під навісом;
- сервісна шафа за рейковим екраном у дальньому торці навісу;
- суха зона під софітом / у технічному приміщенні.

Не можна:

- замуровувати БЖ у фасад;
- ховати з'єднання без ревізії;
- класти блоки живлення в зону прямої води;
- робити одну довгу LED-лінію без можливості обслуговування.

## Ручне керування і відмовостійкість

Home Assistant - основна логіка сценаріїв, але має бути ручний fallback.

Рекомендація:

- фізичні кнопки/вимикачі працюють як input для реле/контролера;
- кнопка не має просто "рубати" живлення смарт-контролера, якщо це порушує логіку HA;
- передбачити локальне вмикання `Навіс 100%`, `Вхід`, `Сходи`, `Сервіс`.

## Технічні вимоги

- Усі зовнішні групи через УЗО/дифзахист 30 mA.
- Кабелі зовні вести в захисті: труба, гофра, металорукав або захищена конструктивна зона.
- 24V лінії не з'єднувати послідовно "гірляндою" через весь будинок.
- Довгі LED-лінії ділити на сегменти до 3-5 м.
- Для навісу N2 / `light.canopy_neon`: Figma-довжина 12.645 м, координаційна сегментація 3 x ~4.215 м / ~4.22 м; фінальний різ після заміру, перевірки інтервалу різки, падіння напруги і точок живлення.
- Від БЖ/контролера до сегментів вести окремі паралельні підводи.
- Для кожної 24V групи бажано окремий запобіжник/клема після БЖ.
- Блоки живлення брати із запасом 25-30%.
- Для фасаду й навісу IP65 мінімум; для сходів/землі/гравію - IP67.
